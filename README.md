# 🎬 stickman3.7 Animation Asset Library

Repository ini berisi aset modular untuk produksi animasi stickman/karakter komedi secara massal.

## 📂 Struktur Aset
- `Characters/`: Tubuh dasar, kepala, dan ekspresi wajah yang bisa dipertukarkan (swappable).
- `Backgrounds/`: Latar belakang berlapis.
- `Props/`: Objek yang bisa dipegang karakter.
- `Docs/`: Dokumentasi pipeline dan manifest aset.
